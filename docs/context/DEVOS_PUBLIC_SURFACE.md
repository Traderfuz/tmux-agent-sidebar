# DevOS Public Surface

> Generated by: `scripts/lib/context-refresh.sh`
> Refresh with: `bash scripts/devos-context-refresh.sh --workspace . --mode soft --trigger manual`

## Skill And Chain Surface

- `docs/context/DEVOS_SKILLS_INDEX.json` is the machine-readable skill registry.
- `docs/context/DEVOS_CHAINS_INDEX.json` is the machine-readable chain registry.
- `docs/context/skill-disclosure-tiers.yml` controls presentation only: L0 is the validated default core set, L1 browses canonical registry categories, and L2 is explicit full-index search.
- `find-skills` with no query returns L0; an explicit keyword or category searches the complete registry, including non-L0 skills.
